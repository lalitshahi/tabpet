# Promo video source

Animated in a canvas page (`index.html`, uses `../../src/pets.js`, copy it next to the page plus the Nunito font as `nunito.woff2`), filmed frame by frame with Playwright and encoded with ffmpeg (`render.py`). Music is a short synthesized loop. Output: `../tab-pet-promo.mp4`, 1920x1080, 30 fps, 39 s.
